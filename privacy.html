プライバシーポリシー

「鍵ダッシュボード」（以下「本ツール」）は、合同会社鍵（以下「当社」）が自社の業務のためだけに使う社内用ツールです。当社以外の利用者はいません。

1. 取得する情報

本ツールは、当社が許可した当社自身のGoogleアカウントについて、Google APIを通じて次の情報にアクセスします。

  • Gmail：メールの読み取り（予約確定・売上報告などの業務メール）と、当社宛ての通知メールの送信
  • Googleカレンダー：予約の予定の読み取りと書き込み

2. 利用目的

民泊の予約管理、宿泊税・会計の帳簿の準備、社内向けの通知に限って使います。

3. 保管と第三者提供

取得した情報は当社の管理するコンピュータにだけ保管し、第三者への提供・販売・広告への利用は行いません。

本ツールによるGoogle APIから受け取った情報の利用と他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

4. 削除

アクセスの許可は Googleアカウントの設定 からいつでも取り消せます。保管した情報の削除は下記の連絡先までご連絡ください。

5. 連絡先
